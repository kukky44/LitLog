### LitLog

読書の進捗管理ができるWebアプリケーションです。
本の登録・読書の進捗管理・本にスレッド型でのメモ追加・本の検索ができます。
サイトURL:[https://lit-log-five.vercel.app](https://lit-log-five.vercel.app)

### 使用技術
- Next.js
  - NextAuth.js (認証)
  - next-intl (多言語対応)
- Tailwind CSS
- Prisma
- PostgreSQL
- Vercel

### 機能
- ユーザー登録・ログイン
- 本の登録・削除
- 読書の進捗管理（未読・読書中・読了）
- 本にスレッド型でのメモ追加
- Google Books APIを使用した本の検索
- 言語選択（日本語・英語）
